# Illustrations

Soft clay 3D pictures for step headers and empty states. Like the orbs, they are pictures,
not colour: they never encode state, so they are always `alt=""` and may use colours outside
the app's tokens.

Each file is 384px, square, WebP with transparency, enough for a 128px slot on a 3x screen.
The 2048px masters live on Higgsfield. To re-export, download the background-removed job
below, trim the empty margin, pad it to a square with 4% margin on each side, and resize.
